BENEATH THE SURFACE

Engineering Breakdown.

A small instrument. A deliberate architecture.

01 / LEARN

Deep Learning Pipeline

MIDI-to-Sequence Vectorization uses music21 to map the upper melodic voice to integer pitch, rest and hold tokens on a 16th-note grid.

A two-layer PyTorch LSTM learns from original synthetic exercises with categorical cross-entropy. Temperature-based Token Sampling controls how adventurous the next note can be.

REPRESENTATION39 tokens · 16 steps per bar
02 / COMPOSE

Edge Inference & Performance

Browser Web Workers run the exported model weights off the main thread. In this studio, inference happens on your device.

Keeping inference off the UI thread leaves room for Three.js animation and Web Audio playback. The canvas targets smooth 60 fps animation; actual frame rate depends on your device and display.

EXECUTIONLocal inference · responsive controls
03 / KEEP

State & Storage

A local-first flow keeps guest compositions in LocalStorage in this browser. MIDI and WAV exports let you take a composition with you.

After verified sign-in, new compositions save to an owner-scoped cloud library. Each library request checks identity. Guest history stays on its device; cloud tracks stay out of the guest cache.

INSIDE THE INSTRUMENT

From chords to notes.

The featured piece was sampled from a two-layer PyTorch LSTM using Am, F, C and G at temperature 0.85. Its 109 notes span 16 bars at 96 BPM. The player draws each note at its pitch, start time and duration.

01 / LearnEach MIDI file becomes a sequence of pitches, rests and held notes on a sixteenth-note grid.

02 / SampleYour seed chords start the sequence. Higher temperatures give less probable next notes more weight.

03 / ListenDuring playback, bass and treble from the synthesizer change the movement of the particles.

The demo used 10 synthetic exercises for training and two for validation. Its exported weights run in a browser worker. This small corpus limits the musical styles the model can learn.

HOW A COMPOSITION MOVES

From training to listening.

Training happens offline. The browser downloads public model weights, then composes and plays your music locally.

  1. 01 / OFFLINE

    Train the model

    Original MIDI exercises → music21 → 16th-note tokens → PyTorch LSTM.

  2. 02 / PUBLIC ASSET

    Export weights

    Learned tensors become a versioned JSON asset served with the studio.

  3. 03 / WEB WORKER

    Sample a melody

    Seed chords + temperature → recurrent inference → validated note events.

  4. 04 / MAIN THREAD

    Listen & see

    Web Audio synthesizes the notes. Audio frequencies drive Three.js particles.
